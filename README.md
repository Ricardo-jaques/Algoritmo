# Algoritmo

Repositório criado para armazenar, organizar e acompanhar as atividades desenvolvidas durante as aulas de **Algoritmo** no curso de **Análise e Desenvolvimento de Sistemas (ADS) da SPTech**.

Aqui estão reunidos exercícios e práticas realizados ao longo das aulas, abordando diferentes conceitos fundamentais da programação e da lógica computacional.

O objetivo deste repositório é registrar minha evolução durante o aprendizado, permitindo acompanhar os conteúdos estudados, revisar exercícios e consultar soluções desenvolvidas ao longo do curso.

## 📚 Conteúdos

Entre os conteúdos trabalhados estão:

* Lógica de programação
* Variáveis e tipos de dados
* Operadores
* Estruturas condicionais
* Estruturas de repetição
* Entrada e saída de dados
* Incrementos e decrementos
* Resolução de problemas utilizando algoritmos

## 🎯 Objetivo

Desenvolver e fortalecer minha capacidade de raciocínio lógico e resolução de problemas, construindo uma base sólida para o desenvolvimento de software.

Este repositório também serve como um registro da minha trajetória e evolução durante o curso.
